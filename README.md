# Publicador de Mensajes Asíncrono

Aplicación web desarrollada para demostrar el uso de JavaScript asíncrono. Permite redactar y validar mensajes, enviarlos mediante una solicitud HTTP `POST` con Fetch API a JSONPlaceholder y mostrar dinámicamente la respuesta del servidor en la interfaz.
